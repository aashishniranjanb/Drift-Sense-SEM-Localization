Engineering Architecture

The Drift-Sense++ Pipeline

Modular cascade designed for subpixel spatial accuracy, periodic replica immunity, and ultra-low CPU latency without GPU dependencies.

1. FFT Scale & Rotation Search
Log-polar frequency domain search rapidly recovers coarse zoom and stage rotation.
2. 200-Candidate Pool
Spatial NMS collects candidate peaks, breaking the single-peak greedy trap.
3. Multi-Evidence Ranker
Gradient orientation and 128x128 context disambiguate periodic array twins.
4. Surgical Pose & Calibration
2-D paraboloid subpixel fitting plus monotone regularized rank confidence.

Forensic Auditing

SEM Failure Mode Taxonomy & Solutions

Systematic characterization of the 5 primary semiconductor failure modes and their engineered safeguards.

Failure Mode 01
Periodic Replica Confusion
Near-identical correlation peaks (ΔNCC < 0.005) cause naive template matching to trap on an adjacent cell replica.
Drift-Sense++ Solution: 200-candidate pool with periodic replica clustering + 128x128 context breaks symmetry.
Failure Mode 02
Degraded True Instance Miss
Heavy Poisson-Gaussian noise and non-uniform SEM charging halos attenuate the physical correlation peak.
Drift-Sense++ Solution: Dual-channel Sobel gradient orientation matching eliminates low-frequency charging halos.
Failure Mode 03
Absent Reference False Accept
Unconstrained localizers force a coordinate selection on background noise for empty search images.
Drift-Sense++ Solution: Two-tier presence gate (PSR < 12.0) enforces found=0 and sets all pose columns to 0.
Failure Mode 04
Confidence Score Inversion
Raw cross-correlation scores correlate poorly with actual subpixel localization error on noisy SEM lattices.
Drift-Sense++ Solution: Monotone regularized rank calibration achieves monotonic ordering (Spearman ρ = 0.832).
Failure Mode 05
Subpixel Quantization Error
Discrete pixel argmax search introduces up to ±0.707 px error, missing tight ≤1 px credit tiers.
Drift-Sense++ Solution: Continuous 2-D paraboloid surface fitting solves the analytical extremum.
