# Drift-Sense++ Failure → Fix Matrix

This matrix maps every critical SEM imaging failure mode to its naive vulnerability and the specific algorithmic mechanism engineered into Drift-Sense++ to neutralize it.

| Failure Mode | Naive Approach | Why It Fails | Drift-Sense++ Solution | Engineering Mechanism | Visual Evidence |
|---|---|---|---|---|---|
| **Periodic Replica Trap** | Raw single-peak NCC / Phase Correlation | Traps on adjacent cell replica ($\Delta\text{NCC} < 0.005$) caused by periodic DRAM/FinFET lattice | **200-Candidate Pool + Replica Family Clustering** | Identifies lattice periodicity vector; groups peaks into families; selects candidate with highest orthogonal structural consensus. | `DEMO/02_periodic_replica_failure.png` & `p2_failure_panel.png` |
| **Heavy Noise & Charging** | Direct spatial pixel template matching | Noise variance and charging halos skew $L_2$ distance and raw correlation scores | **Dual-Channel Gradient & Phase-Only FFT Matching** | Normalizes zero-frequency charging drift; matches directional edge gradients rather than absolute intensities. | `p2_success_panel.png` |
| **Unknown Scale Drift (8x–12x)** | Fixed-template search | Complete loss of correlation peak sharpness beyond $\pm 10\%$ scale mismatch | **Coarse-to-Fine Frequency Domain Pyramidal Search** | Log-polar scale space sweep followed by parabolic subpixel frequency interpolation. | `p2_pose_accuracy.png` |
| **Unknown Stage Rotation (±5°)** | Fixed-orientation template matching | Severe peak degradation for rotations $> 1.5^\circ$ | **Polar FFT Angular Sampling + Spatial Frequency Refinement** | Angular coarse search combined with localized polar phase refinement centered on candidate site. | `p2_pose_accuracy.png` |
| **Reference Absence (Set C)** | Forced coordinate selection on highest noise peak | Generates false-positive detections on empty fields of view | **Two-Tier Presence Gate (V28-C)** | Evaluates Peak-to-Sidelobe Ratio (PSR), ambiguity index, and contextual support. Sets `found = 0` when thresholds fail. | `p2_calibration_roc.png` |
| **Subpixel Quantization Error** | Integer grid peak extraction ($\text{arg max}$) | Quantization error up to $\pm 0.707\text{ px}$, failing tight $\le 1\text{ px}$ and $\le 2\text{ px}$ credit tiers | **2-D Continuous Paraboloid Fitting** | Solves analytical vertex $(\delta_x, \delta_y)$ of $3\times 3$ correlation neighborhood via Hessian inversion. | `p2_error_cdf.png` |
| **Confidence Inversion** | Raw correlation coefficient as confidence | High correlation on periodic noise creates inverted confidence vs true error | **Two-Stage Monotone Calibrator (V48)** | HistGradientBoosting classifier predicts error probability, followed by monotone bucketed regrading ($\rho = 0.832$). | `p2_calibration_roc.png` |
| **Format & Invariant Violation** | Non-zero coordinates when target is absent | Penalized for invalid output specifications | **Architectural Output Barrier** | Guarantees $\text{found} = 0 \implies x=y=\theta=\text{scale}=0$ before any CSV row is written. | `verification/run_all.py` |
